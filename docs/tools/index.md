# Tools

Memoria Web is a browser tool for reading a Memoria store through your own domain assemblies: the
events appended to it, the aggregates and projections snapshotted from them, and the types both were
written through.

It lives in the repository rather than on NuGet, so you build and run it yourself. Start with
[Memoria Web](memoria-web.md) for what each page shows.
