# Upgrading

One guide per release that needed one: what changed, what breaks, and the edit to make. Work through
them in order if you are skipping several versions — each assumes the one before it has been applied.

Every release is listed in the [release notes](release-notes.md), including those that needed no
upgrade guide at all.
